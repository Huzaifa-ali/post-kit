# Visual System (AI/Tech)

## Post Nature → Visual Approach

| Signal | Visual |
|--------|--------|
| Pricing, cost, $ | Screenshot of pricing page OR data card |
| Benchmarks, model names | Dark UI data card with real stats |
| Company + drama | Real photo + text overlay |
| "vs", comparison | Split panel with logos/stats |
| Humor, irony | Source real meme OR generate absurdist scene |
| Layoffs, jobs | Stock photo + bold text overlay |
| Enterprise, fund | Simple text card on black |
| GitHub, repo | Screenshot of actual repo |
| Regulation, law | Official photo + overlay text |
| Opinion, hot take | NO image. Plain text wins. |

## Media Selection Order

Real media beats generated — a real screenshot can't look AI-averaged.

1. Real screenshot of actual thing discussed
2. Sourced meme from Instagram/Reddit (meme posts only)
3. Stock photo/video (Pexels, Unsplash)
4. Simple text card (named dark bg + readable text)
5. AI-generated (LAST RESORT — prompts must pass the slop check: no vibe adjectives, named background, specific detail baked in, exact text quoted)

## Specs

- LinkedIn feed: 4:5 portrait (1080x1350)
- Data cards/comparisons: 1:1 (1080x1080)
- Video: 9:16 vertical, 3-10s memes, 15-30s demos, always text overlay

## Skip Generation When

Real screenshot IS the content, viral meme carries the emotion, post is text-only opinion, or TV show clip would outperform.
