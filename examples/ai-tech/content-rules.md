# Content Rules

## Length by Type

| Type | Length |
|------|--------|
| Meme/roast | 1-4 lines |
| News + opinion | 50-80 words |
| Data/pricing + screenshot | 2-4 lines |
| Opinion/hot take | 50-100 words |
| Life/personal | 80-150 words |

If the visual carries the content, text should be SHORT.

## Structure

```
[Hook — 1-2 lines]
[Body]
[CTA — drives comments or shares]
// Link in first comment
```

## Mandatory Rules

- ONE genuine personal opinion in quotes ("like this") per post
- Short sentences. 1-2 lines per paragraph.
- Hook in first 2 lines (the "see more" gate)
- One idea per post
- CTA invites disagreement or experience-sharing
- Links in comments only
- Pass: "Would someone save this?" OR "Would someone share this?"
- Pass the generic test (below)

## The Generic Test

Could this exact line sit under a post about a completely different topic? If yes, it's slop filler. Replace it with the specific number, name, or fact that makes it about THIS story. "This is huge" works for anything — "$544 vs $4,811, same task" works for exactly one story. Specific beats clever. Applies to captions AND any text baked into an image.

## No Company Bias

Treat all AI companies equally. Roast whoever deserves it. Praise whoever earned it. If it feels like shilling, rewrite.

## Roast Rules

**Roast:** companies, hype merchants, marketing vs reality gap, public figures making public claims.
**Never roast:** individual devs, customers, anyone based on identity.
**Default:** Medium. Spicy for genuine bad behavior. Nuclear once a month max.

## Authenticity

Never claim untested experiences. Never fabricate data. Default: commentary, not personal narrative. Only "I tested/built" if you actually did.

## Sources Credibility

- Tier 1 (official announcements): share freely
- Tier 2 (press/reporting): attribute
- Tier 3 (blogs/newsletters): add context
- Tier 4 (social media claims): verify first

## Hooks by Type

| Type | Hook Style |
|------|-----------|
| Pricing | "$X/month for Y." |
| Roast | "[Company] just did [thing]." |
| AI news | "Everyone's celebrating X. I think it's a problem." |
| Meme | Visual + 1-4 line setup |
| Life | Open in the moment |
| Opinion | Lead with the opinion. Disagreeable > agreeable. |
